
Project Structure

Create a folder:

sorting-project/
│
├── SortingServer.java
└── index.html
✅ STEP 1: Java Backend Code

🔹 1. Compile Java

Open terminal inside folder:

javac SortingServer.java

🔹 2. Run server
java SortingServer

You should see:

Server running at http://localhost:8000

✅ STEP 2: Frontend code

Double click index.html
OR open in browser
